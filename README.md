# Тоннель FW

**Тоннель FW** — Windows-утилита, которая разрешает приложениям выходить в интернет только при включённом VPN и позволяет управлять соответствующими правилами брандмауэра Windows.

Обычный «запускатор по ярлыку» проверяет VPN только в момент старта. Тоннель FW добавляет жёсткий уровень: если VPN отключился после запуска или `.exe` открыт напрямую, приложение **всё равно остаётся без сети** — ограничение работает на уровне брандмауэра.

Версия 3.1 — широкое desktop-окно вместо телефонной колонки: боковая панель, мастер-детейл приложений и полноширинная таблица правил. Чёрно-красная тема, анимации и эффекты курсора сохранены.

## Макет окна

Окно открывается в размере 1120×720, минимальный размер — 980×620, окно можно растягивать и разворачивать на весь экран. Вся раскладка на `Dock`/`TableLayoutPanel`, поэтому элементы перестраиваются при изменении размера.

- **Боковая панель (224 px)**: логотип и версия, навигация «Приложения» / «Правила» с анимированной красной полосой, карточка VPN-адаптера с индикатором ●/○, кнопка «Эффекты» внизу.
- **Страница «Приложения» (мастер-детейл)**: слева поиск, фильтры «Все» / «С правилами», список приложений с точками-индикаторами, кнопка «Выбрать .exe…» и поле ссылки; справа карточка выбранного приложения — иконка, имя, полный путь, кнопка «Открыть папку», переключатель «Ограничение включено», сводка правил и блок «Ярлык» (название, переключатель «Только через VPN», кнопки «Создать ярлык» и «Удалить правила»). Пока ничего не выбрано, справа показывается пустое состояние.
- **Страница «Правила»**: полноширинная таблица с колонками Программа · Действие · Состояние · Интерфейсы · Имя правила, панель действий (⟳, Включить, Выключить, Удалить, Папка) и фильтр. Ниже — карточка редактирования выбранного правила.

## Возможности

- Список приложений из меню «Пуск» плюс все `.exe`, для которых созданы правила TunnelFW.
- Индикаторы в списке: красная точка со свечением — ограничение включено, серое кольцо — правила есть, но выключены.
- Включение и выключение ограничения одним переключателем, переход в папку приложения.
- Создание ярлыков с компактным значком и отдельным `AppUserModelID` (ярлык закрепляется на панели задач отдельно).
- Проверка состояния VPN-адаптера перед запуском цели.
- Чёрно-красный дизайн, анимации наведения/нажатия/волны у кнопок, анимированные переключатели и навигация.
- Эффекты курсора: красное свечение и кольцо при клике; отключаются кнопкой «Эффекты».
- Поиск по приложениям и по правилам, выбор `.exe`, ссылка `https://`.

## Обозначения цветов

Красный — активное или подключённое состояние, серый — выключенное.

| Где | Красный | Белый | Серый |
|---|---|---|---|
| Список приложений | ограничение включено | — | кольцо: правила есть, но выключены |
| Таблица правил | **Block** / «включено» | **Allow** | правило выключено |
| Статус VPN | ● адаптер подключён | — | ○ адаптер не подключён |

## Как это работает

Есть два уровня защиты.

**1. Проверка при запуске.** Ярлык передаёт приложению имя VPN-адаптера и цель. Если адаптер не в состоянии `Up`, программа не стартует.

**2. Ограничение в брандмауэре.** Для `.exe` создаются два правила исходящего трафика:

| Правило | Действие | Область |
|---|---|---|
| `TunnelFW-B-<хеш>` | **Block** | все сетевые адаптеры, **кроме** выбранного VPN |
| `TunnelFW-A-<хеш>` | **Allow** | только выбранный VPN-адаптер |

В Windows блокирующие правила имеют приоритет над разрешающими. При включённом VPN срабатывает только разрешение на VPN-адаптере; при выключенном — путь через физический адаптер закрыт. Имена правил детерминированы из пути `.exe` (MD5-хеш), поэтому повторное создание ярлыка обновляет правила, а не добавляет дубликаты.

## Использование

### Страница «Приложения»

1. Запустите `TunnelFW.exe` — список приложений загружается сразу.
2. Найдите программу поиском, включите фильтр «С правилами» или выберите `.exe` кнопкой «Выбрать .exe…».
3. В карточке справа проверьте путь и нажмите «Открыть папку», если нужно.
4. Переключатель **«Ограничение включено»** включает и выключает правила для приложения (доступен, если правила уже созданы).
5. В блоке «Ярлык» введите название, оставьте переключатель **«Только через VPN (брандмауэр)»** и нажмите **«Создать ярлык»**. Подтвердите UAC.
6. **«Удалить правила»** снимает ограничение полностью — удаляет оба правила для выбранного `.exe`.

### Страница «Правила»

1. Откройте страницу — список правил `TunnelFW-*` обновляется в фоне; ⟳ обновляет вручную.
2. Выберите строку таблицы. В карточке снизу появятся путь программы, действие, VPN-адаптер, переключатель «Включено» и поле интерфейсов через `;`.
3. **Смена VPN-адаптера** пересоздаёт оба правила пары — приложение продолжит работать только через этот адаптер. Смена пути `.exe` переносит правило на новую программу и убирает старое.
4. **«Применить изменения»** пересоздаёт правило, **«Сбросить»** возвращает значения выбранной строки.
5. Кнопки **«Включить» / «Выключить»** переключают выбранное правило, **«Удалить»** удаляет его с подтверждением, **«Папка»** открывает папку программы.

Изменения правил выполняются в фоне с запросом UAC, окно при этом не подвисает.

## Горячие клавиши и запуск

- `TunnelFW.exe` — открыть окно на странице «Приложения».
- `TunnelFW.exe --rules` — открыть сразу страницу «Правила».
- `TunnelFW.exe "<VPN-адаптер>" "<цель>"` — режим ярлыка: запускает цель только при подключённом VPN.

## Ограничения

- Жёсткое ограничение работает только для `.exe` с полным путём. Для ссылок (`https://…`) и приложений Windows выключите переключатель — остаётся только проверка VPN при запуске через ярлык.
- Если менять интерфейсы вручную (поле через `;`), правило меняется отдельно от пары. Для согласованного изменения используйте выбор VPN-адаптера.
- Удаление одного правила на странице «Правила» не удаляет парное. Для полного снятия ограничений используйте «Удалить правила» на странице «Приложения».
- Список «чужих» адаптеров фиксируется при создании правил. После появления нового адаптера пересоздайте ярлык.
- Файловые правила `-Program` действуют на один процесс. Хелперы (`node.exe` и т.п.) нужно ограничивать отдельно.
- Удаление ярлыка с рабочего стола не удаляет правила брандмауэра.
- Кастомный курсор действует в пределах окна приложения; системный курсор Windows не меняется.

## Проверка и удаление правил вручную

```powershell
Get-NetFirewallRule -DisplayName 'TunnelFW-*' |
    Format-Table DisplayName,Enabled,Direction,Action

Get-NetFirewallRule -DisplayName 'TunnelFW-B-*' |
    Get-NetFirewallInterfaceFilter
```

```cmd
netsh advfirewall firewall delete rule name="TunnelFW-B-<хеш>"
netsh advfirewall firewall delete rule name="TunnelFW-A-<хеш>"
```

## Сборка из исходников

Нужны Windows и встроенный компилятор .NET Framework (`csc.exe` из `Microsoft.NET\Framework64\v4.0.30319`).

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "src\build.ps1"
```

Сборка рисует `TunnelFW.ico` и компилирует все файлы `src\*.cs` в `TunnelFW.exe` в корне проекта.

- `src/Program.cs` — точка входа, ярлыки, работа с брандмауэром и PowerShell.
- `src/Ui.cs` — тема, кнопки, переключатели, навигация, эффекты курсора.
- `src/MainForm.cs` — окно и страницы.
- `src/build.ps1` — сборка.
