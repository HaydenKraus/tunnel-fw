# Тоннель FW

Копия приложения «Тоннель» с добавленным **ограничением через брандмауэр Windows**.

Оригинальная папка `..\Тоннель` не изменена.

## Что добавилось

В окне создания ярлыка появился флажок **«Только через VPN (брандмауэр Windows)»** (включён по умолчанию) и кнопка **«Удалить правила»**.

При создании ярлыка для `.exe` программа, помимо самого ярлыка, создаёт два правила брандмауэра:

| Правило | Действие | Область |
|---|---|---|
| `TunnelFW-B-<хеш>` | **Block** (исходящий) | все сетевые адаптеры, **кроме** выбранного VPN |
| `TunnelFW-A-<хеш>` | **Allow** (исходящий) | только выбранный VPN-адаптер |

Приоритет у блокирующих правил выше, чем у разрешающих, поэтому:

* при включённом VPN пакеты идут через VPN-адаптер — срабатывает только разрешение;
* при выключенном VPN единственный путь — физический адаптер — закрыт блокирующим правилом;
* приложение остаётся без сети, **даже если запустить его .exe напрямую**, минуя ярлык.

Правила создаются с повышением прав (UAC). Если компьютер уже запущен от имени администратора, запрос не появляется.

##Как пользоваться

1. Запустите `TunnelFW.exe`.
2. Выберите программу (кнопка «Выбрать .exe…», например Claude Desktop), введите название ярлыка.
3. Выберите VPN-адаптер из списка.
4. Оставьте флажок «Только через VPN (брандмауэр Windows)» включённым и нажмите «Создать ярлык на рабочем столе».
5. Подтвердите UAC. После этого программа выходит в интернет только при включённом VPN.

Чтобы снять ограничение: выберите тот же `.exe` и нажмите «Удалить правила».

##Ограничения

* Ограничение работает **только для `.exe` с полным путём**. Для ссылок (`https://…`) и приложений Windows из `shell:AppsFolder` снимите флажок — там остаётся только проверка VPN при запуске через ярлык (как в оригинале).
* Правила привязаны к конкретному пути `.exe` и имени VPN-адаптера. При переустановке программы или смене адаптера создайте ярлык заново.
* Правила действуют на конкретный процесс. Если приложение запускает network-активность через **другие** процессы (хелперы, `node.exe` и т.п.), для них нужно создавать отдельные правила.
* Список «чужих» адаптеров фиксируется в момент создания правил. Если позже появится новый сетевой адаптер, повторите создание ярлыка, чтобы обновить правила.
* Удаление ярлыка с рабочего стола **не удаляет** правила брандмауэра — используйте кнопку «Удалить правила».

##Ручная проверка / удаление

```powershell
Get-NetFirewallRule -DisplayName 'TunnelFW-*' | Format-Table DisplayName,Enabled,Direction,Action
Get-NetFirewallRule -DisplayName 'TunnelFW-B-*' | Get-NetFirewallInterfaceFilter
```

```cmd
netsh advfirewall firewall delete rule name="TunnelFW-B-<хеш>"
netsh advfirewall firewall delete rule name="TunnelFW-A-<хеш>"
```
