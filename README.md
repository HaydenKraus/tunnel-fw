# Тоннель FW

**Тоннель FW** — Windows-утилита, которая разрешает приложениям выходить в интернет только при включённом VPN и позволяет управлять соответствующими правилами брандмауэра Windows.

Обычный «запускатор по ярлыку» проверяет VPN только в момент старта. Тоннель FW добавляет жёсткий уровень: если VPN отключился после запуска или `.exe` открыт напрямую, приложение **всё равно остаётся без сети** — ограничение работает на уровне брандмауэра.

Версия 3.0.1 — минималистичный чёрно-красный интерфейс: кастомные вкладки, анимированные кнопки и переключатели, эффекты вокруг курсора.

## Возможности

- **Вкладка «Приложения»**: все приложения из меню «Пуск» плюс все `.exe`, для которых созданы правила TunnelFW. Кнопка **«Папка»** открывает папку выбранного приложения в Проводнике, кнопка **«Вкл./Выкл.»** включает или выключает ограничение.
- **Вкладка «Правила»**: все правила с префиксом `TunnelFW-*`, найденные в системе, со статусом, действием, адаптерами и путём программы. Правила можно включать, выключать, удалять и редактировать.
- Создание ярлыков с компактным значком и отдельным `AppUserModelID` (ярлык закрепляется на панели задач отдельно).
- Проверка состояния VPN-адаптера перед запуском цели.
- Чёрно-красный дизайн, анимации наведения/нажатия/волны у кнопок, анимированные переключатели и подчёркивание вкладок.
- Эффекты курсора: красное свечение и кольцо при клике. Отключаются кнопкой **«Эффекты»** в шапке окна.
- Поиск по приложениям, выбор `.exe`, ссылка `https://`.

## Обозначения цветов

Красный — активное или подключённое состояние, серый — выключенное.

| Где | Красный | Белый | Серый |
|---|---|---|---|
| Список приложений | ограничение включено (точка со свечением) | — | кольцо: правила есть, но выключены |
| Список правил | **Block** | **Allow** | правило выключено |
| Строка статуса VPN | ● адаптер подключён | — | ○ адаптер не подключён |

## Как это работает

Есть два уровня защиты.

**1. Проверка при запуске.** Ярлык передаёт приложению имя VPN-адаптера и цель. Если адаптер не в состоянии `Up`, программа не стартует.

**2. Ограничение в брандмауэре.** Для `.exe` создаются два правила исходящего трафика:

| Правило | Действие | Область |
|---|---|---|
| `TunnelFW-B-<хеш>` | **Block** | все сетевые адаптеры, **кроме** выбранного VPN |
| `TunnelFW-A-<хеш>` | **Allow** | только выбранный VPN-адаптер |

В Windows блокирующие правила имеют приоритет над разрешающими. При включённом VPN срабатывает только разрешение на VPN-адаптере; при выключенном — путь через физический адаптер закрыт. Имена правил детерминированы из пути `.exe` (MD5-хеш), поэтому повторное создание ярлыка обновляет правила, а не добавляет дубликаты.

## Использование

### Вкладка «Приложения»

1. Запустите `TunnelFW.exe` — список приложений загружается сразу.
2. Найдите программу поиском или выберите кнопкой **«Выбрать .exe…»**.
3. **«Папка»** — открыть папку приложения; **«Вкл./Выкл.»** — переключить его ограничение (доступно, только если правила есть).
4. Введите название, выберите VPN-адаптер, оставьте переключатель **«Только через VPN (брандмауэр)»** включённым и нажмите **«Создать ярлык на рабочем столе»**. Подтвердите UAC.
5. **«Удалить правила»** снимает ограничение полностью — удаляет оба правила для выбранного `.exe`.

### Вкладка «Правила»

1. Откройте вкладку — список правил `TunnelFW-*` обновляется в фоне; кнопка **⟳** обновляет его вручную.
2. Выберите правило. Ниже появятся его поля: программа, действие (`Block`/`Allow`), VPN-адаптер, переключатель «Включено» и список адаптеров через `;`.
3. Измените нужные поля и нажмите **«Применить изменения»** — правило пересоздаётся с новыми параметрами. Если вы изменили путь `.exe`, парное правило обновляется автоматически. **«Сбросить»** возвращает значения выбранного правила.
4. Кнопки **«Включить» / «Выключить»** переключают выбранное правило, **«Удалить»** удаляет его (с подтверждением), **«Папка»** открывает папку программы правила.

Изменения правил требуют прав администратора — появится запрос UAC. Чтение списка правил работает без повышения прав.

### Эффекты курсора

Кнопка **«Эффекты»** в правом верхнем углу включает и выключает красное свечение вокруг курсора и кольцо при клике. Эффекты рисуются отдельным прозрачным слоем поверх окна и не мешают кликам. Если включённый слой на слабой машине вызывает подтормаживание — выключите его этой кнопкой.

## Ограничения

- Жёсткое ограничение работает только для `.exe` с полным путём. Для ссылок (`https://…`) и приложений Windows из `shell:AppsFolder` снимите переключатель — остаётся только проверка VPN при запуске через ярлык.
- Редактор меняет **одно выбранное правило**. При смене действия или адаптера второе правило пары остаётся прежним — это осознанно, чтобы можно было редактировать правила независимо. Для согласованного изменения лучше пересоздать ярлык.
- Удаление одного правила на вкладке «Правила» не удаляет парное. Для полного снятия ограничений используйте **«Удалить правила»** на вкладке «Приложения».
- Список «чужих» адаптеров фиксируется при создании правил. После появления нового адаптера пересоздайте ярлык.
- Файловые правила `-Program` действуют на один процесс. Хелперы (`node.exe` и т.п.), если приложение использует их для сети, нужно ограничивать отдельно.
- Удаление ярлыка с рабочего стола не удаляет правила брандмауэра.
- Кастомный курсор действует в пределах окна приложения; системный курсор Windows не меняется.

## Проверка и удаление правил вручную

```powershell
Get-NetFirewallRule -DisplayName 'TunnelFW-*' |
    Format-Table DisplayName,Enabled,Direction,Action

Get-NetFirewallRule -DisplayName 'TunnelFW-B-*' |
    Get-NetFirewallInterfaceFilter
```

```cmd
netsh advfirewall firewall delete rule name="TunnelFW-B-<хеш>"
netsh advfirewall firewall delete rule name="TunnelFW-A-<хеш>"
```

## Сборка из исходников

Нужны Windows и встроенный компилятор .NET Framework (`csc.exe` из `Microsoft.NET\Framework64\v4.0.30319`).

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "src\build.ps1"
```

Сборка создаёт `TunnelFW.ico` и компилирует `TunnelFW.exe` в корне проекта.

- Исходник: `src/TunnelFW.cs`
- Скрипт сборки: `src/build.ps1`
